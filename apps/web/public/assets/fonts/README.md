# Compendium display font

`compendium-heading.ttf` is the Noto Serif SC 600 subset for `万象集录Compendium`, downloaded from Google Fonts on 2026-11-05. It is self-hosted; rendering makes no request to Google Fonts. Existing UI/body typography is unchanged. Its new filename prevents cached copies of the previous heading subset from omitting the new characters.

Source CSS: https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@600&text=%E4%B8%87%E8%B1%A1%E9%9B%86%E5%BD%95Compendium
