# Compendium display font

`compendium-heading.ttf` is the Noto Serif SC 600 subset for `万象集录Compendium`, downloaded from Google Fonts on 2026-11-05. It is self-hosted; rendering makes no request to Google Fonts. Existing UI/body typography is unchanged. Its new filename prevents cached copies of the previous heading subset from omitting the new characters.

Source CSS: https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@600&text=%E4%B8%87%E8%B1%A1%E9%9B%86%E5%BD%95Compendium

Upstream license: https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt (SIL OFL 1.1; included in LICENSE.txt).

`characters-heading.ttf` uses the same Noto Serif SC 600 face, subset to
`群星图鉴Character Archive`, downloaded on 2026-11-05 and self-hosted under the
same included SIL OFL license. The separate asset preserves the existing
Compendium subset and cache identity.

Source CSS: https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@600&text=%E7%BE%A4%E6%98%9F%E5%9B%BE%E9%89%B4Character%20Archive
