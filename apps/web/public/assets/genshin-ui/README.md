# Genshin Impact UI icons

Ten unmodified original PNG sprites, obtained from the community mirror
[PathOfGenshin/resources](https://github.com/PathOfGenshin/resources/tree/015a2493b5672b28576ab78ffbcffde2ea0c9844/resources/gi/Sprite)
at commit `015a2493b5672b28576ab78ffbcffde2ea0c9844` on 2026-11-05.

- `UI_BtnIcon_CodexBooks`: 尘世文卷 / Teyvat Archive navigation.
- `UI_BtnIcon_Bag`: 万象集录 / Compendium navigation.
- `UI_BtnIcon_AvatarList`: 群星图鉴 / Character Archive navigation.
- `UI_Icon_Element_{Fire,Water,Wind,Electric,Ice,Rock,Grass}`: Pyro, Hydro,
  Anemo, Electro, Cryo, Geo and Dendro. Unknown elements have no substituted icon.

The white transparent originals are tinted only through presentation CSS.
`manifest.json` records exact source URLs, dimensions, SHA-256 and Git blob hashes;
each downloaded file was checked against the pinned repository tree.
