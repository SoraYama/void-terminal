# 群星图鉴与万象集录详情切换骨架

## 1. 背景

切到未缓存的角色时，`CharacterWorkspace` 用居中的「正在读取角色资料」替换整个详情，头像条和键盘焦点一起消失。万象集录的详情在请求标记更新前会先进入未选中状态，再显示独立读取提示。

## 2. 实现

- `CharacterDetail` 固定头像条与返回按钮，按当前分区布置骨架。基础属性表和天赋倍率预留数值位置，立绘位置保留到图片就绪。
- `ItemDetail` 在桌面侧栏和手机弹层共用标题区、返回按钮与图片区域。武器和圣遗物预留属性值位置，道具说明和标签也留有骨架。
- 标题、星级、头像或道具图来自当前语言和快照下的列表摘要；数据未到时显示「—」，不读取上一条记录的数值。详情缓存直接命中；请求仍可取消，响应身份不符时显示重试入口。

## 3. 验证

Chromium 回归用例分别挂起角色和武器详情请求，检查摘要、返回按钮、头像焦点与数值占位，再释放请求核对真实数值。两个用例都覆盖桌面和手机视口。现有回归同时覆盖缓存返回、浏览器历史、快照错误与重试等路径。此次为本地变更，未发布。

类型检查和正式构建通过；Web 单测 485 项通过。两个图鉴的 Chromium 套件共 64 项通过，4 项沿用现有的手机跳过规则。
