# 全图入口误标「前往旧日之海」与入口图标修正

用户在 `teyvat-atlas-7.2-hd.html` 反馈全图入口都显示「前往旧日之海」，双向箭头下钻图标难以辨认。

## 根因

`prototypes/world-map/atlas.js` 的入口绘制沿用了枫丹原型的固定文案：所有 `kind=entrance` 都写「前往旧日之海」，所有 `exit` 都写「返回枫丹」。源数据的六个 `targetMapKey` 不同，原点击跳转根据 key 解析正确，但显示文字与跳转用了两套逻辑。旧 Canvas 图标只是黄色矩形中的 Unicode 双向箭头。

在修改前 Chromium 聚焦渊下宫入口，记录实际 Canvas `fillText`，输出六次「前往旧日之海」，断言缺少「前往渊下宫」失败；同目录 `atlas-portals-before.png` 保存可见错误。

## 修复

- `drawPortals()` 将名称和按钮动作绑定到同一个解析后的目标场景；支持六张独立地图，出口实际目标为主图时显示「返回提瓦特」。未知目标不画成可点击入口。
- 将跨场景入口改为与 Canvas 坐标同步的原生按钮；门洞 SVG 配进入向下/返回向上箭头，44px 点击区域。近景、悬停、键盘聚焦显示目的地文字，支持 Enter/手机点击，切图后焦点回到地图。
- 楼层视图隐藏跨场景按钮；画布可访问名称同步实际场景。资源、聚合数字圆点、楼层资源与入口数据不变。
- 回归发现 DOM 入口截住一根触点会令双指缩放失效：实际命中分别为 Canvas 和旧日之海入口 SVG。将画布/入口的 Pointer 与 wheel 事件交给同一地图容器处理，拖动或多指手势不触发入口跳转；按钮保留键盘激活。
- 同步重建高清和离线两个 7.2 HTML，当前已打开的文件需刷新才能运行新代码。
