# 尘世文卷、原版导航图标与角色元素标识

## 1. Background & Problem

用户选定「尘世文卷」替代原文库，并同意书籍、背包、角色图鉴的原版导航图标。随后提供纳西妲详情页标注图，要求使用七元素图标，并将姓名区域和元素标识移到头像条下方。标注箭头落在立绘区域左上角、分区菜单右侧。

## 2. Approach

英文入口使用 Teyvat Archive；保留原文阅读等功能用语和既有路由。十枚原版 PNG 来自固定社区镜像提交 `PathOfGenshin/resources@015a2493b5672b28576ab78ffbcffde2ea0c9844`，逐一校验 PNG 格式、尺寸与 Git blob 哈希，仅 CSS 着色。素材、SHA-256、来源链接见 `apps/web/public/assets/genshin-ui/manifest.json`，版权说明见根目录 THIRD_PARTY_NOTICES.md。

角色身份区位于头像条下方，姓名、称号与元素组合展示；桌面保留左侧分区菜单、立绘和属性列，手机按头像条、分区菜单、身份区、内容排列。元素图标用于筛选、卡片和详情；旅行者按所选形态更新，未知元素不补造图标。保持可访问名称与深浅主题。

## 3. Validation

首轮命名、图标与身份区下移的本地验证（后续五项排版调整见下文）：

- Web 单测 15 个文件、288 项通过；TypeScript 与 Next.js 生产构建通过。原有 Vite config-loader 提示仍存在。
- 生产模式角色与文卷阅读回归 35 passed、3 项既有手机跳过，覆盖新身份区域、七元素筛选、旅行者形态、空元素回退、头像/资料/语音/材料快照、侧栏折叠、手机抽屉和长文阅读。
- 更名影响的文卷筛选、选段提问、长文本与精确原文显示另有 4 项桌面/手机场景通过（`library-flow-production.log`）；合计 39 项浏览器场景通过、3 项既有跳过。
- 真实数据的 1440×1000 桌面 / 390×844 手机与深浅主题共四组验收通过：10 个本地图标均可解码；七元素筛选、名称区域下移、三入口图标、尘世文卷标题、英文 Teyvat Archive 与旅行者风→岩切换正常；无页面错误、水平溢出或模型调用。
- 独立审查核对增量代码、原标注图、四组截图与十枚 PNG 哈希，未发现需要修复的问题。最终生产截图为 `artifacts/navigation-elements/production-preview.png`；其余截图、验收 JSON、测试及构建日志在同目录。

首次测试的诊断记录予以保留：普通沙箱禁止测试桥接服务监听（EPERM），允许本地监听后 288 项通过；初版验收脚本每次导航重置语言，修正脚本初始化后四组通过；开发模式浏览器回归 34 passed / 3 skipped / 1 failed，trace 显示 Next dev overlay 拦截折叠按钮点击，切换生产构建后同套 35 passed / 3 skipped。均无须修改产品代码来绕过。

此轮仅修改本地前端和素材文档，不变更后端快照，不提交、推送或发布。本地生产模式预览保留在 `http://127.0.0.1:3123/characters`；不等同于生产部署或独立打包验收。

### 后续：姓名区与属性列对齐

用户进一步指定五项调整：元素图标前置、姓名加粗并去除可见元素文字；星级紧随姓名；武器类型接在称号后；属性标题与姓名平齐；立绘上移。实现将属性页改为共用两列网格：左列身份区与立绘，右列属性区跨两行。其他页签保留身份区。手机单列按身份、立绘、属性排列，图标仍提供本地化可访问名称，旅行者按所选形态更新。

本轮生产构建（含 TypeScript）与 22 项角色桌面/手机浏览器回归通过。另以真实数据检查桌面/手机深浅主题、820px 平板和 1280px 英文长姓名，共六组通过；无横向溢出或页面错误。1440px 纳西妲详情的姓名和属性标题顶部均为 y=142；元素图标位于姓名前，五星位于姓名后，副标题为「白草净华 · 法器」。立绘舞台高度调整为 620px（原约 755px），保持原图比例，减少垂直居中产生的上方空白。

本轮证据：`artifacts/navigation-elements/identity-build.log`、`identity-e2e.log`、`identity-results.json`、`identity-*.png`。桌面最新截图为 `identity-desktop-light.png`。首轮旧截图与记录继续保留作为历史对比；仍未提交或发布。
