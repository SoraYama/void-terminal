# 回答图鉴卡片与角色浏览

## 1. Background & Problem

询问「芙宁娜是谁？」等具体资料时，回答需要有可继续浏览的图文资料。群星图鉴的详情头像条原先沿用列表筛选后的单页数据，按星级进入会漏掉另一星级。武器卡的星级也会压住图片边缘。

## 2. Root Cause / Approach

卡片复用引用中已有的源记录身份，并通过现有 Knowledge 详情接口验证语言、快照和文献归属。回答完成时最多返回三张卡片；记录缺失、错快照、加载超时或没有匹配主题时，文字和引用照常可读。卡片不接受模型生成的素材或跳转 URL，不需要重建快照。

## 3. Key Changes

- `lib/server/answer-cards.ts` 匹配实际引用的角色、武器和圣遗物，使用图鉴已有的图片验证规则。套装文献用对应套装部件作图并链接回该部件的套装说明。
- `done.cards` 随历史保存。卡片按引用编号定位到正文段落，在左侧浮动，文字从右侧绕到下方。旧历史无编号时按卡片名称匹配；极窄内容区改为上下排。跳转固定同一快照，复制和导出仍使用原回答正文。
- `use-character-pool.ts` 在详情中独立读取同快照的跨页角色名单；元素通过 `browseElement` 只筛头像，保留列表的四／五星筛选、搜索和滚动。历史记录和浏览器返回仍可恢复。
- 武器网格星级放在图片下方，保留武器详情和其他道具原有排版。

## 4. Conclusions / Lessons

验证必须覆盖实际引用、旧快照及历史记录恢复；角色详情需用小于总数的分页夹具验证池子完整性。本次变更不涉及线上模型调用和部署。
