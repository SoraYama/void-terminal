# 提瓦特舆图入口与浏览正文语言

**后续状态：** 接收端已完成推送、PR 合并与生产发布，见[发布与回滚记录](../misc/2026-11-11-atlas-release.md)。下文中的未发布状态是原实现/离线交接时的历史记录。

## 背景与范围

用户要求首页左侧导航能进入地图页，并修复英语界面下角色、装备等正文仍是中文的问题。沿用现有原作菜单风格，命名为「提瓦特舆图 / Teyvat Atlas」。整批地图与语言修改已本地提交为 `df1251a`；尚未成功推送或部署。用户要求因公司环境限制停止远端操作，转交另一台机器，见 [离线交接记录](../misc/2026-11-11-map-handoff.md)。

## 实现与根因

- `Terminal` 新增 `map` 视图与 `/map` 页面；桌面侧栏、收起导航与手机抽屉共用入口。离开页面记住查询 URL，浏览器前进后退与刷新恢复选择。导航图标来自原型中自绘的折叠地图，使用透明 SVG mask，未冒称原版游戏贴图。
- `MapWorkspace` 复用 `ResourceMapCards` 高清 Canvas 和真实只读查询，不需要模型密钥。`/api/maps/catalog` 返回完整地区/资源目录与固定快照；国度、地区、资源搜索及下拉选择会查询并更新 URL，未校准区域不会伪装成零。
- 地图 `countryEn` / `parentNameEn` 从已核验的国家映射和父区目录补齐，卡片和目录契约保持向后兼容。英文页面展示 Port Ormos / Sumeru / Ardravi Valley / Dendroculus。
- 原因是角色、装备与原文浏览错误使用 `prefs.sourceLanguage`。它原本是独立的考据语料语言，切 UI 英语不会同步。浏览页面改用 `prefs.locale`；对话仍保留独立语料语言与回答语言，引用保持原文。切 UI 语言时取消旧原文读取、清除旧文档/选区并回到第一页，按当前语言列表重新选择原文；不伪造另一语言的文档 ID。
- 角色和装备的既有缓存已包含语言、快照、记录 ID，无需替换缓存结构。详情继续保留布局、摘要与骨架，慢请求不会回填到另一种语言。
- 审查补充发现 `region=稻妻` 这类本地化筛选值随语言切换保留，后端英文目录会得到零结果。`CharacterWorkspace.accept` 用接口返回的当前语言完整地区集合核验；确认无效时清空地区、重置第一页并保留其他稳定筛选与快照。覆盖英语冷启动打开旧中文链接；有效地区在其他筛选无结果时仍保留。
- 视觉复核发现蓝色地图标题在风景上对比不足。复用既有图鉴的浅色场景前景与深色遮罩，手机收紧说明与间距，保留 44px 控件。

## 证据与边界

真实地图目录是 `map-7.2-4b27a05e0004aab7`：597 地区、759 资源类型。奥摩斯港草神瞳为 2 点；风起地风神瞳为 6 点，并保留边界待复核状态。

只读 SQLite 核验了真实英文资料：`data/characters-preview/catalog.sqlite` 中绫华简介/故事/天赋/命座/地区，以及 `data/catalog-release.sqlite` 中护摩、角斗士之花和哀叙冰玉碎屑的说明/词条。浏览器 `archive-language.json` 是从这两份库抽出的双语子集，明确标记 fixture，不等同于主站连接完整知识服务。

当前本地 8000 端口没有知识服务，默认 `data/catalog.sqlite` 不存在；角色和装备资料分处两份库，registry 按快照选单库，不会合并补缺。本次没有合并/改写原 SQLite，也没有扩大为重建全量数据。地图服务可单独运行，图鉴正文用上述真实资料夹具验证。

全量 Web 32 文件、567 项单测及生产构建通过。地图入口先在旧构建复现缺失；中文地区切英语/英文旧链接的两个用例先失败，有效英文地区通过，修复后最终浏览器 28 项通过、2 项既定手机跳过（1.3m），包含桌面浅色、手机深色及原聊天卡片回归。地图与英文资料截图留存 `artifacts/atlas-language/`。

新增浏览器回归覆盖：无需模型 Key 的地图入口/真实查询/URL恢复、国度/区域/资源筛选、不可用场景、英语正文、双向切换/缓存、迟到的中文角色与武器响应、原文库切换和有效地区保留。既有考据「英文回答+中文语料」契约保持独立。

最后的修复验证包含：地区筛选三个场景在桌面和手机均通过；地图跨国度/区域/资源选择，风起地 6 个风神瞳与待复核提示、独立场景拒绝状态；旧考据中英文语料隔离与列表滚动恢复。初次扩展地图选择测试误用 textbox 定位 search 输入，修正为其实际 searchbox 角色后完整复跑通过。

Impeccable detector 已运行一次，仅报告既有设计文档未逐项列出的色值/字号/圆角 advisory，没有自动修改共享设计系统。当前图鉴与装备正文采用真实本地双语记录的受控接口测试；未宣称统一知识服务或真实模型联调。

独立复审确认两个 P2 已关闭：无效本地化地区筛选恢复、地图标题对比度。最新桌面浅色/手机深色截图中标题采样对比约 11.38:1；手机地图起始位置由约552px提前到472px。复审未发现新增P1/P2，结论仅覆盖本轮代码与视觉修复，不代替线上服务验收。
