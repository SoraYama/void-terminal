# 图鉴界面视觉与旅行者立绘补充

群星图鉴的角色卡原先按星级铺底，属性表只有文字，旅行者缺少快照立绘。卡片改用火、水、风、雷、冰、岩、草七种元素底色；无元素记录使用中性底色。星级仍按源记录呈现，群星图鉴和万象集录共用浅暖金色的原版 `UI_IconStar`。

`resolveCharacterPortrait` 优先使用 `allowedCharacterImage` 认可的快照立绘。只有角色 ID、Avatar ID 和头像标识均符合旅行者清单时，才在无可用快照图或图片加载报错后回退到本站保存的原始立绘。两幅透明图的构图按画面高度缩放，保留人物和武器；快照记录、媒体白名单和语音来源不变。「来源与覆盖」仍展示快照覆盖，并另外给出补充立绘的固定提交链接。清单内的原图保留了 Git blob 和 SHA-256。

属性图标按标准键映射，兼容 `FIGHT_PROP_` 前缀，未知键保留文字；格式化数值沿用原逻辑。群星图鉴、万象集录和尘世文卷的正文与控件使用本地 Noto Sans SC 变量字体；品牌和模块标题保留原显示字体。101 个带哈希的 WOFF2 子集通过 `unicode-range` 按需加载，许可证和来源见 `THIRD_PARTY_NOTICES.md`。

Web 单测 485 项通过，类型检查和生产构建通过。桌面与移动浏览器替换外部图片响应验证 404 回退，同时核对覆盖状态、补充来源链接、图标与本地字体请求。用只读快照 `character-preview-53eea8cb88906a53`（134 条正式角色记录）验证桌面浅色卡片、男女旅行者立绘、纳西妲元素精通、390px 移动端立绘和属性表，以及深色草元素列表。截图与浏览器记录保存在本地 `artifacts/archive-polish/real-ui/`；六个样本没有外部字体请求或横向溢出。未部署或发布。
