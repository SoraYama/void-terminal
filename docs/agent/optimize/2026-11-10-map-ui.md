# 地图六条浏览器批注：完整导航、资源聚合与默认高清

用户针对 `teyvat-atlas-7.2-hd.html` 标出六处修改：页头图标参考游戏重绘，导航不再仅突出枫丹/古堡/旧日之海，地图选择器与信息牌对齐且箭头留白一致，右侧同类神瞳合并，移除高清开关并默认高清。沿用当前纸面/蓝灰/金色设计及 Canvas 地图交互。

## 改动与边界

1. 从既有游戏 UI 镜像的固定修订取得 `UI_BtnIcon_Map.png`（64×60），目视确认折叠地图、虚线路线和终点叉号。以这些轮廓重绘 `icons/map.svg`，替换水滴六边形徽记。来源 URL、哈希在 `prototypes/world-map/icons/README.md`。
2. 顶部生成提瓦特及源配置全部七个地区：蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬。独立/分层地图菜单包含渊下宫、层岩巨渊、旧日之海、远古圣山、空之神殿、霜月，以及褪色古堡。手机地区标签可横向滚动，地图菜单独占下一行。
3. 地区标签与选择器双向同步。沿用源配置相机中心定位；既有枫丹视图保留明确的点位集合。其他地区仍在主图数据集内，汇总的范围标记为「提瓦特」，没有用最近中心伪造地区行政边界或地域点数。
4. `.plate`、地区选择器、独立地图选择器共用宽度变量：桌面 176px，手机 156px。原生 select 保留键盘语义，移除原生外观，统一 SVG 下拉箭头。文字左内边距 12px，箭头距右侧内边缘 12px；测试包含边框后的外边距均为 13px。
5. 资源列表按真实类型 `t` 汇总，默认主图神瞳从逐点重复变为 8 行，共 1,549 处。点击类型筛选并定位其点位，提供返回全部分类的操作；地图仍画全部匹配点并按原算法聚合。纯数字或 `#编号` 按源 ID 精确查询单点，保留详细位置、分层和入口定位。其他资源也采用类型汇总。
6. 移除 `.quality`、`#hd`、`#quality-status` 控件和用户文案，两种输出文件名都默认高清，断网仍用内嵌底图。`--offline` 为显式离线构建选项；`--online-hd` 仅保留既有高清文件名。网络恢复事件清理失败请求缓存。没有更改原生瓦片、楼层图的精度上限。
