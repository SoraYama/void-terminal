# 枫丹 Canvas 地图原型

在[枫丹跨源坐标实测](2026-11-09-fontaine-map-match.md)后，用 AppSample 的公开瓦片、楼层图和标点完成会话本地原型 `fontaine-atlas.html`。地图、索引及样本数据都在一个 HTML 中，用浏览器直接打开。原型没接入站点，也没把第三方图片和点库写入仓库。

后续交付见 [7.2 全场景与图标](2026-11-10-atlas72.md)：89,091 个源标点、七场景、六枚重绘图标及可复用原型代码；本页记录第一版枫丹样本。

## 交互与数据

- Canvas 绘制当前相机视野的底图瓦片，再叠加楼层、聚合标点和入口指引。两张地图使用各自的瓦片金字塔，采样层级为 10–13；支持拖动、滚轮、双指缩放和方向键。公开 [AppSample 前端](https://genshin-impact-map.appsample.com/_next/static/chunks/3aiymv_i7elpl.js)的 centered tile 文件行号朝北递增，必须以 `canvasRow = -sourceRow - 1` 放入向下的 Canvas 瓦片格；直接使用文件行号会在错误的地形画点。标点和楼层边界使用经纬投影，不能套用旧版米游社像素坐标。
- 按中文、英文、标点 ID 或别名搜索，和当前资源分类叠加。枫丹视野范围沿用对照样本：225 个水神瞳、435 个五种品质宝箱、487 个摩拉与枫丹藏物箱标记、640 个区域特产点（苍晶螺、海露花、柔灯铃、虹彩蔷薇、幽光星星、子探测单元、湖光铃兰、初露之源）。素材筛选暂不含首领、敌人、商店或秘境掉落。
- 褪色古堡 B1–B4 用不同底图和明确的楼层 ID 筛选。当前楼层可显示关联入口，选点画指引虚线，点详情的洞口或通路按钮定位入口。指引线表示来源关联，不是自动寻路或可达性保证。
- [旧日之海](https://genshin-impact-map.appsample.com/sea-of-bygone-eras/)有独立瓦片、镜头和 46 个水神瞳。标签页和来源配置中的跨场景入口都能切图；从有楼层数据的旧日之海标点可查看其所在楼层。
- 采用 AppSample 2026-11-09T07:39:05.819Z 的[公开点位文件](https://game-data.b-cdn.net/gim/markers_all.v5.compressed.json)筛出 1,965 条枫丹标点和 233 条旧日之海标点（含入口和锚点）；瓦片 109 + 149 张、楼层图 4 + 8 张。此原型用于本地检视；对外发布仍需确认第三方资产与数据使用范围。

## 验证

- 用 Chromium 1440×950 和 iPhone 13 尺寸打开本地 HTML：滚轮、拖动、双指缩放，搜索「湖光铃兰」返回 79 点，宝箱筛选返回 435 点，搜索「摩拉袋」在全分类返回 487 点。
- B1–B4 神瞳筛选数量分别是 3、0、1、2；B1 点 `69148` 的指引可定位洞口 `68938`。旧日之海显示 46 个水神瞳、91 个摩拉类点；验证独立楼层查看及从枫丹 Canvas 上点击入口切图。
- 225 个枫丹和 46 个旧日之海水神瞳，在四个瓦片层级的源图片像素检查全部命中有效地图；桌面和手机预览均完成截图检查。
