# void-terminal · 原神素材视觉修订 v2

日期：2026-10-28。用户认为 v1 太写实，像中土世界，明确建议使用原神自己的 Logo、风景等素材。该反馈覆盖此前「原创幻想海港」与「不使用官方 Logo」的选择。总体功能、Docker、双 Key 与视觉先于编码的要求保持不变。

## 修订方向

以官方原神须弥场景与 Logo 作为实物素材，建立可识别的提瓦特视觉。保留探索和知识问答的主题，不再把自创写实海港、哥特高塔、密集星轨作为主视觉。

- 背景直接引用官方场景，不重新设计地区建筑、植被与地形，不换成西方奇幻城堡。
- 图像质感保持游戏本身的动画渲染、清晰色块和柔和光照；不能增加照片式石材、电影写实细节或画外月球。
- 游戏 Logo 作为 IP 识别，产品名称仍是 void-terminal／虚空终端。页面保留小型「非官方原神知识站」说明，避免被理解成官方服务。
- UI 借鉴游戏菜单的温润米白、灰蓝、柔和金色、简洁几何纹样；正文用清晰圆润的无衬线，减少高反差宋体与厚金框。
- 公开展示的配图来源分别记录，官方来源不等于宣称全资产获得通用再分发许可。

## 页面

1. 首页：官方须弥场景构成主画面，小型原神 Logo、void-terminal 品牌与清晰提问框；布局现代、字体更轻快，主体保持原神自身风格。
2. 对话：灰蓝/米白的真实文字阅读区与原文抽屉，场景仅作为轻背景或页头，保留来源、停止和连续问答。
3. 浅色阅读：同一套原神菜单色彩与 Logo，场景横幅、篇章、正文、问原文。
4. 手机：匹配新版首页和对话，不沿用 v1 的写实城堡背景。

## 交付边界

生成设计稿会以这些真实素材作为参考并要求保留其内容，但概念图仍是 AI 合成稿，不能承诺输出每个像素与素材一致。最终实现须直接使用原始场景与 Logo 文件，不使用生成器重绘的 Logo 或整页截图来冒充页面组件。当前不写产品代码；待用户审查修订稿。
