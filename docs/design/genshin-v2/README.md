## 视觉决定

- 保留探索与旅行的产品结构，实际美术改为原神自身场景；不会沿用 v1 的写实石材、海港高塔、巨月或密集星轨。
- 原神 Logo 用作游戏识别；产品品牌仍为 void-terminal／虚空终端，保留小型「非官方原神知识站」说明。
- 浅色以米白、灰蓝和柔和金色为主，深色用深灰蓝、奶油白文字与低亮度边线；背景里的青绿来自须弥场景，而非另做一套绿色终端。
- 标题和正文趋向清晰、圆润、轻盈的游戏菜单感，不再用高反差衬线大字制造西方史诗氛围。
- 首页保留大场景；聊天和阅读让原文清楚，风景仅作小范围背景。
