## 视觉决定

首页完整呈现幻想海港夜景，文字与输入区通过压暗和实色底保证清晰；进入聊天后风景退出正文，保留边缘星轨。浅色阅读页以细长晨光海港横幅延续品牌，不变成羊皮纸风格。

品牌固定为四芒星罗盘与小写 void-terminal，中文名为虚空终端。主色采用午夜蓝、星金、月光白；浅色转为晨光白、雾蓝、深海蓝。全套沿用细线图标、克制金边、圆形发送/停止控件以及金色引用编号。

桌面聊天的引用出现在右侧；移动端改为可关闭的底部面板，打开时覆盖并停用下面的聊天输入区。原文阅读中的高亮片段与助手引用相互对应。

## 后续实现时必须保持的要点

- 这四张是视觉参考，不允许把整张生成图作为可交互网页。背景插画需要独立制作/导出，导航、文字、引用和输入框应实现为真实组件。
- 文字、颜色、间距、控件与布局使用一致的设计 token；产品内容变化后仍保持本稿的层级与留白。
- 标题保留衬线气质，正文与功能控件采用清晰无衬线；生成图片中的字形与字号只能作为参考，最终以真实字体渲染和可读性为准。
- 移动端按实际屏幕宽度重排，考虑软键盘、安全区、焦点和滚动；生成图不代替响应式浏览器验证。
- 示例文字、引用编号和原文占位不是已检索的游戏内容。不得将示例段落作为生产语料或默认模型答案。
- 设计稿中的金色外框/角标若属于展示板，不进入实际手机网页；「视觉设计稿 · 内容示意」仅用于评审。
- 图中已避开附件、麦克风、账号和其他首版未规划功能。

## 生成与检查

生成方式：内置 image_gen。01 为新生成母版，02/03/04 均以 01 为参考图派生；每张一次生成。工具未提供底层模型选择字段，不声称指定了 image 2.5。所有完整提示词均在同目录保存。

已逐张查看图片，检查主操作、品牌、正文、引用与手机布局。概念图仍有生成器导致的细微字形/字体差异，实际实现需要使用正确的真实文案。当前稿用于评审风格、构图和视觉层级，不是 Figma 源文件或已实现网站。
