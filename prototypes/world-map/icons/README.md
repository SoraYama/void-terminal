# Icon references

`map.svg` is a geometric redraw of the folded map and dotted route in the game's
`UI_BtnIcon_Map.png`, adapted to the prototype's brass/paper colors. The former
water-drop/hexagon emblem has been removed.

Reference: [PathOfGenshin/resources, pinned revision](https://raw.githubusercontent.com/PathOfGenshin/resources/015a2493b5672b28576ab78ffbcffde2ea0c9844/resources/gi/Sprite/UI_BtnIcon_Map.png).
The inspected original is 64×60 PNG, SHA-256
`8a3230370cb6638454f27f333c9d645e1c3c4372eb9b3e94bf5b7ae72bcd66a0`.

The six numbered resource SVGs use the matching AppSample item sprites as visual
references: Hydroculus (508), Beryl Conch (500), Lakelight Lily (548), Rainbow Rose
(503), Exquisite Chest (44), and Mora (127). They are prototype redraws, not a claim
to be original game exports. Other resource images remain source sprites.
